# 🐍 100 Days of Python

A structured 100-day Python learning journey — from complete beginner to advanced developer.

---

## 📚 Curriculum Overview

| Phase | Days | Topics |
|-------|------|--------|
| Phase 1 | 1–25 | Python Basics & Fundamentals |
| Phase 2 | 26–50 | Intermediate Python |
| Phase 3 | 51–75 | Advanced Python |
| Phase 4 | 76–100 | Real-World Projects & Libraries |

---

## 🗂️ Project Structure

```
100DaysPython/
├── Phase1_Basics/           # Days 01–25: Fundamentals
├── Phase2_Intermediate/     # Days 26–50: OOP, Files, Modules
├── Phase3_Advanced/         # Days 51–75: Decorators, Generators, Concurrency
├── Phase4_Projects/         # Days 76–100: Real-World Projects
└── README.md
```

---

## 🚀 How to Use

1. Clone this repository
2. Navigate to the day's folder
3. Open the `.py` file and read through the commented examples
4. Run the file: `python dayXX.py`
5. Modify and experiment!

---

## 🛠️ Requirements

- Python 3.8+
- No external libraries needed for Phase 1–3
- Phase 4 requirements listed per project
